Integracje i ekosystem

System monitoringu rzadko działa sam - łączymy go z Home Assistant, Node-RED, MQTT i akceleratorami AI.

HA · Node-RED · MQTT+ AI edge

System monitoringu wizyjnego rzadko działa w izolacji. Deweloperzy łączą go z platformami automatyzacji (Home Assistant, OpenHAB), wizualnymi edytorami flow (Node-RED) oraz własnymi mikroserwisami opartymi na MQTT i REST API. Detekcja oparta na AI może być realizowana lokalnie (akceleratory edge) lub poprzez API.

Home Assistant #

Home Assistant to wiodąca platforma open-source automatyki domowej. Kamerę RTSP podpinasz jako encję camera, a Frigate integruje się natywnie przez MQTT - tworzy encje kamery, sensorów detekcji (person/car/...) oraz binary sensorów zajętości. Automacje reagują na zdarzenia: „jeśli osoba na bramie po 22:00 - zapal światło i wyślij powiadomienie".

yaml
# configuration.yaml - kamera RTSP w HA
camera:
  - platform: generic
    name: Brama
    stream_source: rtsp://user:pass@192.168.1.10:554/stream1
    still_image_url: http://192.168.1.10/snapshot.jpg

Node-RED #

Node-RED to wizualny edytor flow oparty o Node.js - łączy zdarzenia z logiką bez pisania kodu. Typowy flow monitoringu: wejście MQTT z Frigate (frigate/events) → node funkcji filtrujący obiekty → switch (osoba vs samochód) → wyjścia (powiadomienie Telegram, webhook, zapis do bazy). Świetne do prototypowania logiki reaktywnej, zanim przeniesiesz ją w stały kod.

MQTT - krwiobieg IoT #

MQTT to lekki protokół pub/sub, naturalny klej między kamerami, NVR i automatyzacją. Broker (mosquitto, vernemq) pośredniczy w wiadomościach, a tematy strukturują dane. Frigate publikuje zdarzenia detekcji, HA je subskrybuje, Node-RED reaguje.

bash
# struktura tematów
frigate/available            # online/offline
frigate//person      # snapshot + bounding box
frigate//recordings  # start/stop nagrywania
homeassistant/camera/brama/config  # autodiscovery HA

Akceleratory AI #

Detekcja AI bywa realizowana lokalnie (edge) lub poprzez API. Wybór zależy od opóźnień, prywatności i budżetu. Lokalna inferencja na akceleratorze utrzymuje dane w Twojej sieci - kluczowe dla prywatności. API (rozpoznawanie twarzy, OCR tablic) jest wygodne, ale wysyła klatki poza dom.

Prywatność

Lokalna inferencja (Coral, Jetson) utrzymuje klatki w Twojej sieci - to domyślny wybór dla domowego monitoringu. API chmurowe rezerwuj do rzeczy, których nie da się zrobić na edge (OCR tablic, rozpoznawanie twarzy z dużym słownikiem).
