Deploy na GitHub Pages #

Ta witryna jest w pełni statyczna - żadnego backendu ani build-stepu. Hosting na GitHub Pages sprowadza się do wgrania plików i kliknięcia „Save".

  1. Wrzuć pliki do repozytorium (gałąź main, katalog root lub /docs).
  2. Settings → Pages → Source: Deploy from a branch → wybierz gałąź i katalog.
  3. Plik .nojekyll (zawarty w paczce) wyłącza filtrowanie Jekyll - katalog assets/ serwuje się poprawnie.
  4. Custom domain: w polu Custom domain wpisz czwarta.eu. Dla apex dodaj rekordy A wskazujące IP GitHub Pages (185.199.108-111.153); dla subdomeny - CNAME na USER.github.io. Włącz „Enforce HTTPS".
  5. Podgląd lokalny: python3 -m http.server 8000 w folderze witryny, potem otwórz http://localhost:8000.
Edycja treści

Treść generuje skrypt scripts/gen_pages.py - zmień w nim odpowiednią stronę i uruchom ponownie, albo edytuj pliki .html bezpośrednio. Design i interakcje żyją w assets/style.css i assets/app.js.
